Proyecto de data science

## Aplicación de visualización

La aplicación Streamlit incluye los gráficos principales del análisis exploratorio de `notebooks/EDA.ipynb`. Selecciona un gráfico en el menú para cargarlo; así se evita calcular todos los gráficos en cada interacción. Los gráficos marcados como filtrados excluyen anuncios con precios inferiores a $500 y superiores al percentil 99.

Desde la carpeta `Sprint-7---Proyecto`, inicia la aplicación con:

```bash
streamlit run app.py
```
